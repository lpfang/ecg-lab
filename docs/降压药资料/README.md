## 网站上的取舍

- **剂量**只写中国指南 2024 表 15（复方为表 16）的一般范围，不抄说明书：转载的说明书版本互相矛盾，旧版说明书剂量（如氢氯噻嗪 25–100 mg/日）也高于现在的用法。
- **商品名和企业**只写记录里有来源的；记录标为"未核实"的，页面上写明"未核实"或不写。
- 国内是否有售没有把握的，卡片上标"国内供应未核实"或"国内未上市"：氯噻酮、米诺地尔（口服）、阿利吉仑、阿普昔腾坦标为未核实，奈必洛尔标为未上市。
- 少数记录之外的事实，另用 openFDA 核对过：卡托普利 1981、氯沙坦 1995 年在美国获批；各单片复方的美国商品名与停产状态；Procardia XL 说明书中"空药壳随大便排出"；Toprol-XL 说明书中缓释片 47.5 mg 相当于酒石酸美托洛尔 50 mg。

## 已知会变化的信息

企业并购、持有人转让、新一批集采、医保目录调整都会让这些信息过时。下次更新时重新核查，并改 `build_drug_list.py` 里的 `CHECKED` 日期。
