## 一、一句话定位

**真实 12 导联心电图 ↔ 心电向量 ↔ 心脏电活动，三者在同一时间轴上联动**，并且每个知识点都有**通俗版**和**专业版**两层讲解。

核心原理：**每个导联 = 心电向量在该导联轴上的投影**。这条原理用真实数据实时演示，而不只是示意图。

## 二、两类学员，一套系统

### 1. 分层讲解（贯穿全站）

每个知识点写成两层：

- **通俗版（默认展开）**：一两句话 + 生活类比，不出现公式。
  例："心电图像从 12 个角度给心脏的电活动拍照。电流朝着某个'相机'跑，这个相机就记录到向上的波。"
- **专业版（点"展开"）**：定义、数值标准、机制、出处。
  例："导联电压等于心电向量在导联轴上的投影（点积）……Sokolow-Lyon 标准：SV1 + RV5/V6 ≥ 3.5 mV。"

全局有一个"通俗 / 专业"偏好开关（记在浏览器里），决定默认展开哪一层，两层都随时可看。术语表每条同样分两层：中文（English）· 一句话解释 · 专业定义。

### 2. 两条学习路线

| | 患者路线：读懂我的心电图 | 医学生路线：系统读图 |
|---|---|---|
| 目标 | 看懂报告单上的词，知道心电图能说明什么、不能说明什么 | 掌握系统读图顺序和常见诊断标准 |
| 内容 | 心电图怎么做（电极贴哪）；报告单常见术语；高血压与心脏；降压药对心电图的影响；手表 / 家用单导联心电图能看什么；什么情况该及时就医 | 导联系统、各波段与间期、电轴、阻滞、肥厚、缺血 / 梗死、心律失常、电解质 |
| 测验 | 术语认读、"这张图哪里是 P 波"等基础题 | 定位、测量、诊断、找错题 |

两条路线共用同一批病例和工具，只是讲解深度和导览顺序不同。

### 3. 高血压专题（两类学员的交汇点）

高血压对心脏的影响在心电图上有迹可循，这是本项目对患者最有价值、对医学生也很实用的专题：

- **左心室肥厚（LVH）**：电压标准（Sokolow-Lyon、Cornell 等）**在本例上实时计算**，显示"本例 SV1 + RV5 = x.x mV"，并说明各标准的阈值和适用人群。
- **劳损型 ST-T 改变（strain pattern）**：外侧导联 ST 压低 + T 波倒置。
- **左心房增大**：P 波增宽、V1 的 P 波终末负向部分。
- **房颤**：高血压是房颤的常见危险因素；在长条带上看 RR 绝对不齐、P 波消失。
- **降压药与心电图**：β 受体阻滞剂 → 心率减慢、PR 可能延长；利尿剂 → 低钾 → U 波明显、QT 延长；ACEI / ARB / 螺内酯 → 可能升高血钾 → T 波高尖。
- **一个诚实的说明**：心电图诊断左室肥厚的**敏感性较低**，"心电图正常"不等于"没有左室肥厚"。超声心动图更准确。这对患者很重要，可以避免过度放心或过度担心。

### 4. 对患者的边界（必须遵守）

- 本站是**教学工具，不解读用户自己的心电图**。不提供上传个人心电图的功能，也不给出个人诊断或用药建议。
- "什么时候该就医"只讲通用的警示信号（如胸痛、晕厥、心悸伴头晕），并统一指向"请咨询医生"。
- 每个页面底部显示免责声明。

## 三、核心联动（原理部分）

| 视图 | 内容 | 联动方式 |
|---|---|---|
| 心电图纸 | 3×4 标准排版 + II 导联节律条，真实 mm 网格，标定脉冲 | 拖动时间光标 / 点击某个波 |
| 心电向量环（3D） | 用 Kors 回归矩阵把 I、II、V1–V6 换算成 X/Y/Z，画出 P / QRS / T 向量环 | 光标时刻对应环上的点；可切换额面 / 水平面投影 |
| 导联轴 | 六轴系统（额面）+ 胸导联（水平面） | 选中某导联 → 高亮轴线，显示投影长度 = 此刻电压 |
| 心脏示意（3D） | 程序化简化心脏 + 传导系统 | 按波段驱动：心房除极 → 房室结延迟 → 室间隔 → 心尖 → 侧壁 → 复极 |

通俗版的讲法："拖动这根竖线，就像慢动作回放一次心跳。"

### 导联代数带来的功能（真实数据直接计算）
- **导联错接模拟**（左右手反接 → I 导联倒置等）
- **虚拟导联**：拖动任意角度的轴，生成"从这个方向看到的心电图"
- **电轴**：计算值 vs 目测法（I、aVF 正负）对比
- **Cabrera 排版**

## 四、工具与显示

- **电子卡尺**：两点测 ms / mV / 心率；卡尺复制平移检查节律是否规整。
- **间期面板**：PR、QRS、QT、RR；QTc 多公式并列（Bazett / Fridericia / Framingham / Hodges），注明快 / 慢心率时 Bazett 的偏差。
- **LVH 电压计算面板**（高血压专题用）：列出各标准在本例的计算值和阈值。
- **屏幕校准**：用银行卡（85.6 mm）对齐，未校准时提示"尺寸近似"。
- 走纸 25 / 50 mm/s，增益 5 / 10 / 20 mm/mV，胸导联可单独半增益（LVH 常用）。
- **滤波对比**：诊断模式 0.05–150 Hz（零相位）vs 监护模式 0.5–40 Hz；50 Hz 陷波。
- **波段着色**可关闭，导览第一步默认关闭。
- 所有测量与判分一律按 ms / mV。

## 五、四种学习方式

### 1. 自由浏览
选病例，随意看、量、拖光标。

### 2. 导览（数据驱动）
步骤字段沿用 anatomy-lab：`title / text{plain, pro} / requires / cases / view{speed,gain,filter,layout} / cursor / highlightLeads / probe / next`。讲解文字分 `plain`（通俗）和 `pro`（专业）两层。

候选路线：
1. 心电图是什么：一次心跳的慢动作（患者入门）
2. **高血压与心电图**：正常 → 左室高电压 → 左室肥厚伴劳损 → 房颤（跨病例串联）
3. 正常心电图逐波讲解（医学生入门）
4. 电轴：从六轴系统到本例
5. 房室传导阻滞渐进：正常 → 一度 → 二度 I 型 → 二度 II 型 → 三度
6. 束支阻滞：RBBB vs LBBB 的向量环
7. 心肌梗死定位
8. 滤波与伪差

引用本例数值的路线必须用 `cases` 限定病例。

### 3. 读片手册
- 患者篇：心电图怎么做 → 报告单术语 → 高血压与心脏 → 药物影响 → 家用设备 → 就医信号
- 专业篇：电生理 → 导联系统 → 读图顺序 → 波段与间期 → 电轴 → 各专题

交互演示（M5 已做前两个；合成波形的两个待定，见"以后再做"）：
- 拖动电轴，看六个肢导联变化
- 调心率，看 QT / QTc
- 导联错接切换
- **左室肥厚电压**：调节左室"厚度"，看胸导联电压和各标准判定如何变化（合成波形）
- 血钾高低：低钾（U 波）↔ 高钾（T 高尖 → P 消失 → QRS 增宽）
- 滤波对 ST 段的影响

### 4. 测验
| 难度 | 题型 | 判分 |
|---|---|---|
| 入门 | 报告单术语认读；在图上点出 P 波 / QRS / T 波 | 选择题；定位按 ms 容差 |
| 进阶 | 精确定位起止点；测量 PR、QRS、电轴 | 与 LUDB 人工标注比较（±20 ms，电轴 ±15°） |
| 进阶 | 看向量找导联；认诊断；找技术问题 | 选择题，干扰项取形态 / 角度最相近的 |

作答时锁定波段着色、间期面板、诊断标签、自动电轴。

## 七、没有心内科老师审定：替代措施

没有专业审定是本项目最大的风险，尤其面对患者。对策：

1. **每条诊断标准都注明出处**：写清指南或文献的名称和年份（如 AHA/ACCF/HRS 心电图标准化与解读系列建议、ESC 及中国高血压指南）。所有出处集中在 `content/references.md`，页面上可点开查看。
2. **只写有共识的内容**：存在争议或各指南不一致的地方，并列给出、注明差异，不替读者选边。
3. **用数据库的医生诊断交叉核对**：LUDB 和 PTB-XL 的诊断由医生给出。系统按标准计算的结果（如 LVH 电压）若与医生标签不一致，就列入报告，并在讲解中如实说明"标准与临床判断不总是一致"。
4. **患者内容保守表述**：只解释概念，不做个人判断；涉及"要不要紧"的问题，一律建议咨询医生。
5. **公开注明审定状态**：每页标"内容未经心内科专业人员审定"，并提供反馈渠道（GitHub Issues）。
6. **独立复审**：每完成一批内容，用另一个 AI 会话对照出处逐条核查。这只能减少错误，不能替代专业审定，页面上也这样说明。
7. **以后找到老师时**：内容按条编号、记录审定状态，方便逐条审。

## 九点五、降压药手册（2026-11-13 用户提出，优先于 M6）

用户本人是高血压患者，希望重点开发：由浅入深、准确。

- **市场**：中国大陆为主，附美国商品名。
- **指南**：以《中国高血压防治指南》为主，参照美国 ACC/AHA 和欧洲 ESC；三者不一致的地方并列写出。
- **层次**：
  1. 入门（患者）：为什么要长期吃药、几大类药各是什么、怎么读药盒上的通用名和商品名、常见副作用怎么办、什么情况要找医生。
  2. 按类别（患者 + 医学生）：作用原理、适合谁、不适合谁、常见副作用、对心电图的影响、和其他药的相互作用。
  3. 药物卡片（查询）：每个药一张，可按通用名、商品名、英文名检索。
  4. 专业篇（医学生）：起始治疗与目标值、联合用药的优选与避免组合、合并症下的选择、难治性高血压。
- **"选择推荐"的边界**：只写指南对**一类人群**的一般原则（如"合并糖尿病蛋白尿首选 ACEI 或 ARB"），不针对读者个人推荐具体药物，不对药企或品牌排名。原研与通过一致性评价的仿制药按国家规定视为疗效一致，页面如实说明。每页提示：换药、停药、加药都要和医生商量。
- **企业信息会变**（并购、持有人转让、集采），每条注明核实日期和来源。

## 十、风险与对策

| 风险 | 对策 |
|---|---|
