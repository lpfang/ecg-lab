# 心肌梗死专题的资料与病例核查记录

2026-11-13 整理。读片手册"心肌梗死"（患者篇）、"急性 ST 段抬高型心肌梗死"（专业篇）两章、心梗定位交互演示、"心肌梗死：从急性到陈旧"导览和进阶测验中的两道题都以这里的资料为依据。

## 资料

`criteria.json`：35 条带出处的事实和 12 条未能核实的内容。主要来源：

| 来源 | 读到的程度 |
|---|---|
| 第四版全球心肌梗死定义（Thygesen 2018，Circulation 版） | 全文（出版社网站 403，读的是学会网站转载的 PDF） |
| AHA/ACCF/HRS 2009 心电图标准化建议第六部分（Wagner 2009，JACC 版） | 全文（同上） |
| ESC 2023 急性冠脉综合征指南、ACC/AHA 2025 急性冠脉综合征指南 | 全文（预印 / 提前发布版，页码可能与正式版不同） |
| 中国急性 ST 段抬高型心肌梗死诊断和治疗指南（2019）、ST 段抬高型心肌梗死基层诊疗指南（2019 年） | 全文（中华医学期刊网 HTML，无页码，按章节引用） |
| PTB-XL 论文（Wagner 2020）与 PhysioNet 说明页 | 全文 |

**未能核实、因此网站上没有写或已改为保守说法的**：侧壁 = I、aVL、V5–V6 这类逐条对应表（指南里没有，网站写明是"教学上的习惯分组"）；各演变阶段的固定时间；中国指南对"不要自己开车"的表述（网站引用的是美国 2025 和欧洲 2023 指南）；嚼服阿司匹林等用药建议（网站不写，只说"用什么药听急救人员和医生的"）。

## 病例

从 PTB-XL 中筛选：心梗类诊断标签、梗死分期 Stadium I（急性 / 早期，来自原始报告文字）、经心内科医生确认、无质量标记、没有左束支阻滞 / 起搏 / 左心室肥厚等使 ST 标准失效的标签；并要求 GE 12SL 与 Glasgow 两种算法的 J 点读数**都**在相邻两个导联达到第四版定义的阈值。再人工读原始报告挑选。注意：梗死分期字段是从报告文字自动提取的，和报告措辞并不总是一致（11944 报告写"亚急性"、13913 写"recent"，字段却都是 Stadium I；导览用的陈旧下壁病例 12841 也是 Stadium I），所以网站上的"急性 / 亚急性 / 陈旧"一律按原报告措辞。

| 病例 | 原报告要点 | 本站 J 点读数（mV） |
|---|---|---|
| 12899（67 岁女性） | ST elevated in II, III, aVF; depressed in I, aVL (probably reciprocal); early inferior MI | II 0.19、III 0.31、aVF 0.25；I −0.12、aVL −0.22 |
| 13913（68 岁男性） | Q waves in V2, 3; ST elevated in I, II, aVL, V2–6, especially V2–4; depressed in III; recent anterior and lateral MI | V2 0.82、V3 1.04、V4 0.71、V5 0.37、V6 0.24、I 0.23、aVL 0.14；III −0.06 |
| 2993（85 岁女性） | acute inferolateral infarct with true posterior involvement | II 0.16、III 0.23、aVF 0.19、V5 0.11、V6 0.16；V1 −0.13、V2 −0.34、V3 −0.30 |
| 11944（74 岁男性） | 亚急性前壁梗死；T 波倒置 I、aVR、aVL、V1–5；ST 抬高 V1–4 | V1 0.14、V2 0.20、V3 0.16、V4 0.09 |

本站 J 点读数与 Glasgow 算法逐导联比较：12899、13913、2993 相差都不超过 0.05 mV；11944 本站偏低，V3 相差 0.067、V2 相差 0.051 mV。11944 的 V2 本站 0.195 mV，略低于 74 岁男性 V2 的 0.2 mV 阈值（Glasgow 0.246），所以网站只说"仍轻度抬高"，不说它达到 STEMI 标准。

与正常对照的中位心搏逐例看过：11944 的 V2–V4 T 波倒置、2993 的 V2–V3 ST 段压低、13913 的 V2–V4 ST 段抬高与 T 波融合，均与描述一致。病例都没有冠脉造影资料，"罪犯血管"只按 AHA 2009 的规律说"更像"。

## 独立核查（2026-11-13）

另一个代理对照 `criteria.json` 和病例数据逐条核查，找出 7 处错误或缺少依据的说法、9 处措辞问题，已全部改正。主要有：13913 的 II 导联其实抬高，不符合 AHA 2009 所说"左前降支近段阻塞时下壁导联压低"，因此不再说它是近段阻塞，定位演示里"前壁 + 高侧壁（近段）"一项也不再链接这个病例；STEMI 阈值的前提是"没有左心室肥厚和**束支阻滞**"（不只是左束支）；V1–V3 压低本身并不特异，后壁受累的说法改为"可能"；病理性 Q 波统一用第四版定义的标准；时间目标补上适用条件；补充"心电图已有典型改变时不等抽血结果"。
