# 数据核查记录

## 2026-11-11：LUDB 的幅度不是真实毫伏值

**发现**：在 LUDB v1.0.1 中，每条记录的每个导联峰峰值都**恰好是 1.00 mV**（已检查记录 1、142）。头文件中各导联的增益不同（如 1716、1206 ADC/mV），正好等于该导联的 ADC 范围，即幅度被逐导联归一化。

**独立验证（Einthoven / Goldberger 定律）**：真实 12 导联中，肢体导联由同一组电极电位计算，必须满足 II = I + III、aVF = (II + III) / 2、aVR = −(I + II) / 2。经 0.5–40 Hz 带通滤波后：

| 数据 | II vs I + III 相对误差 | 允许每导联一个缩放因子后 |
|---|---|---|
| LUDB 记录 1 | 51% | 0.0% |
| LUDB 记录 142 | 37% | 0.0% |
| PTB-XL 00001 / 00002 / 00003 / 00010 | 0.08–0.19% | — |

LUDB 允许逐导联缩放后误差为 0，说明波形形态和时间完全真实，只是**每个导联被单独乘了一个系数**。胸导联之间没有类似约束，真实幅度无法恢复。

**影响**：
- LUDB 仍可用于：波形起止点（医生手工标注）、PR / QRS / QT 等时间间期、"找出 P 波"等定位题。
- LUDB 不可用于：任何电压相关内容（左室肥厚电压标准、ST 段抬高 / 压低的 mV 值、电轴、心电向量环、导联代数、按真实 mm/mV 绘图）。

**决定**（用户确认）：**PTB-XL 为主要数据源**（真实 mV，CC BY 4.0），波形边界和测量值来自 PTB-XL+ 中的 GE 12SL、Glasgow Uni-G 算法，标注为"自动测量，未经人工校对"。LUDB 只作辅助，用于时间相关的教学，界面上显示"幅度已归一化"警告。

**流水线防护**：`pipeline/build_case.py` 对每个病例自动做 Einthoven 检查，误差 > 5% 报错误，> 2% 报警告，结果写入 `meta.json` 的 `quality.einthoven`。

## 其他记录

- **全局间期的计算方式会显著影响结果**：LUDB 各导联独立标注，直接取"所有导联最早起点 / 最晚终点"会把单个导联的标注误差叠加，使 QRS 偏宽（记录 142：最宽单导联 88 ms，全局 96 ms）。现改为取第二早起点 / 第二晚终点。
- **PTB-XL+ 两个特征表中 `ecg_id` 的列位置不同**（12SL 不在第一列），必须按列名查找。
- **GE 12SL 特征表没有 QRS 电轴列**，电轴目前只有 Glasgow Uni-G 的结果。
- **PTB-XL 性别编码**：0 = 男，1 = 女；年龄 ≥ 90 岁统一记为 300（隐私保护），本站显示为"≥90"。

## 2026-11-11：电轴计算公式与算法差异

- 额面电轴不能直接用 `atan2(aVF, I)`。按 Einthoven / Goldberger 几何关系，aVF 只等于额面向量投影的 √3/2，正确公式是 `atan2(2/√3 · aVF, I)`；与 6 个肢体导联最小二乘拟合的结果完全一致。ptbxl-33：错误公式 47.5°，正确公式 51.6°。
- 本站计算（QRS 净面积，各心搏中位数）51.6°，Glasgow Uni-G 为 60°，各心搏之间本身就在 42°–58° 波动。不同算法（中位心搏、面积法 / 振幅法、QRS 窗口定义）相差 5–10° 属于常见现象，界面上并列显示，不替读者选。

## 2026-11-11：ECGDeli 自动标注的问题

- 记录起点常落在心搏中间，ECGDeli 会在最前几个采样点上标出一组不完整的 P / QRS；流水线舍弃离首尾 20 ms 以内的波，并写入 issues。
- 被截断心搏的残留点曾被配到下一个心搏，组成"时长 −588 ms 的 P 波"。现改为 P 取离本 QRS 最近的一组点。
- V1 首个心搏出现"T 波起点早于 QRS 终点"，按顺序检查舍弃。

## 2026-11-11：Kors 矩阵核对（12 导联 → Frank 向量心电图）

用 PTB Diagnostic ECG Database（ODC-BY 1.0，同时记录了 12 导联和真实 Frank 导联 vx / vy / vz）核对本站使用的 Kors 回归系数（Kors JA et al., Eur Heart J 1990;11:1083–1092）。0.5–40 Hz 滤波后前 15 秒的相关系数：

| 记录 | X（左右） | Y（上下） | Z（前后） |
|---|---|---|---|
| patient001 | 0.982 | 0.954 | 0.720 |
| patient104 | 0.998 | 0.987 | 0.995 |
| patient150 | 0.998 | 0.992 | 0.533 |
| patient180 | −0.718 | 0.950 | 0.896 |
| patient233 | 0.998 | 0.997 | 0.965 |

结论：系数和坐标约定（X 向左、Y 向下、Z 向后为正）正确；**Z（前后方向）重建误差最大**，界面注明"由 12 导联推导，前后方向误差较大"。patient180 的 X 负相关原因未查明（可能是该记录 Frank 导联极性或电极问题），记录在此。

## 2026-11-12：M2 病例选择与核对

`pipeline/select_cases.py` 按主题从 PTB-XL 筛选（诊断经医生确认、无质量标记、标签干净、两种算法一致），再逐例人工核对。

- **病例描述必须与数据相符**：对每个病例摘要中提到的波形特征逐项用数据核对，不符的修改措辞或换病例。
  - 290（"可能陈旧下壁心梗"）的 II、III、aVF Q 波仅 8–27 ms、0.01–0.05 mV，不能支持"异常 Q 波"的描述，**换成 12841**（Q 波宽 44–74 ms）。
  - 11193（左束支阻滞）V6 的 R 波宽钝但没有明显切迹，删去"有切迹"。
  - 17160（左心房增大）：ECGDeli 标注的 P 波宽 156–176 ms，而 GE 12SL、Glasgow 测得 134、138 ms，ECGDeli 明显偏宽（PR 段只剩约 30 ms）。两种算法仍 > 120 ms，诊断不变；导览改用算法的 P 波时限。V1 P 波终末负向部分约 −0.09 mV（两种算法与本站一致）。
- **左室肥厚伴 ST-T 改变**：14279 不满足任何电压标准且 V1 基线漂移 2.82 mV（数据库未标注漂移），**换成 5971**。
- **心房颤动**：算法仍会输出 PR 值，ECGDeli 会把颤动波标成 P 波。流水线对 AFIB / AFLT 病例舍弃 PR 与 P 波，并写入 issues。
- **R 波定义差异**：本站 R = QRS 内最高正向偏移；GE 12SL / Glasgow 的 R_Amp 只取第一个正向波，多相波中的 R′ 另计。ptbxl-33 的 aVL（QRS 为 +0.04 → −0.05 → +0.17 → −0.10 → +0.18 mV）因此相差 0.13 mV。差异 > 0.2 mV 时流水线自动报告。
- **电压标准的"假阳性"可作教学**：12605（陈旧前间壁心梗）、11193（左束支阻滞）达到 Peguero 标准，但都不是左心室肥厚；左束支阻滞时界面明确提示电压标准不适用。
- PTB-XL 没有病史和用药信息：左室肥厚、房颤、窦缓等病例的说明只写"常见原因之一是……"，并注明"数据库没有提供本例的病史和用药情况"。
- **ECGDeli 的 P 波起止点普遍偏宽**（见 17160）：讲解中引用 P 波时限时优先用 GE / Glasgow 的 `P_Dur_Global`；"此刻"框中按心搏显示的 P 波时限仍来自 ECGDeli，并注明"自动标注"。

## "与正常心电图对照"（M2 补充）

- 对照方法：中位心搏（各心搏按 QRS 起点对齐、减去本心搏 PR 段零点、逐点取中位数）；左心房增大病例按 P 波起点对齐。正常对照按性别取 ptbxl-33（女）/ ptbxl-1779（男）。
- 对照表数值统一取 Glasgow 算法（无则 GE），两份心电图用同一算法。
- 文字描述逐条用中位心搏核对后才写入，核对中改掉的说法：
  - 13904：ST 压低、T 倒置最明显的是 I、aVL（T 最低约 −0.17 mV），V5/V6 只是 T 波低平 / 浅倒（约 −0.06 ~ −0.08 mV）；删去未核实的"下斜型""不对称"。
  - 5971：T 倒置在 V4–V6（V5 最深，约 −0.41 mV），ST 压低主要在 V5、V6（V4 只有约 −0.05 mV），据此改写。
  - 17160：V1 P 波正常对照基本向上（+0.15/−0.01 mV），本例先正后负（+0.08/−0.09 mV），差别明显；II 导联 P 宽只差约 18 ms（算法 138 vs 120 ms），文字如实写"不容易看出来"。
  - 12841：正常对照的 III 导联本身也以 S 波为主（只有很小的起始 r 波），描述改为"II、aVF 一开始就向上，III 先有很小的向上波"。
  - 2239：I、aVL 的 q 波太小（< 0.03 mV），删去"qR"描述。
  - 3953：V1 的 s 波没有降到基线以下（M 形），在专业说明中注明。
