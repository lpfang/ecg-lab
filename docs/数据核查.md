# 数据核查记录

## 2026-11-11：LUDB 的幅度不是真实毫伏值

**发现**：在 LUDB v1.0.1 中，每条记录的每个导联峰峰值都**恰好是 1.00 mV**（已检查记录 1、142）。头文件中各导联的增益不同（如 1716、1206 ADC/mV），正好等于该导联的 ADC 范围，即幅度被逐导联归一化。

**独立验证（Einthoven / Goldberger 定律）**：真实 12 导联中，肢体导联由同一组电极电位计算，必须满足 II = I + III、aVF = (II + III) / 2、aVR = −(I + II) / 2。经 0.5–40 Hz 带通滤波后：

| 数据 | II vs I + III 相对误差 | 允许每导联一个缩放因子后 |
|---|---|---|
| LUDB 记录 1 | 51% | 0.0% |
| LUDB 记录 142 | 37% | 0.0% |
| PTB-XL 00001 / 00002 / 00003 / 00010 | 0.08–0.19% | — |

LUDB 允许逐导联缩放后误差为 0，说明波形形态和时间完全真实，只是**每个导联被单独乘了一个系数**。胸导联之间没有类似约束，真实幅度无法恢复。

**影响**：
- LUDB 仍可用于：波形起止点（医生手工标注）、PR / QRS / QT 等时间间期、"找出 P 波"等定位题。
- LUDB 不可用于：任何电压相关内容（左室肥厚电压标准、ST 段抬高 / 压低的 mV 值、电轴、心电向量环、导联代数、按真实 mm/mV 绘图）。

**决定**（用户确认）：**PTB-XL 为主要数据源**（真实 mV，CC BY 4.0），波形边界和测量值来自 PTB-XL+ 中的 GE 12SL、Glasgow Uni-G 算法，标注为"自动测量，未经人工校对"。LUDB 只作辅助，用于时间相关的教学，界面上显示"幅度已归一化"警告。

**流水线防护**：`pipeline/build_case.py` 对每个病例自动做 Einthoven 检查，误差 > 5% 报错误，> 2% 报警告，结果写入 `meta.json` 的 `quality.einthoven`。

## 其他记录

- **全局间期的计算方式会显著影响结果**：LUDB 各导联独立标注，直接取"所有导联最早起点 / 最晚终点"会把单个导联的标注误差叠加，使 QRS 偏宽（记录 142：最宽单导联 88 ms，全局 96 ms）。现改为取第二早起点 / 第二晚终点。
- **PTB-XL+ 两个特征表中 `ecg_id` 的列位置不同**（12SL 不在第一列），必须按列名查找。
- **GE 12SL 特征表没有 QRS 电轴列**，电轴目前只有 Glasgow Uni-G 的结果。
- **PTB-XL 性别编码**：0 = 男，1 = 女；年龄 ≥ 90 岁统一记为 300（隐私保护），本站显示为"≥90"。
